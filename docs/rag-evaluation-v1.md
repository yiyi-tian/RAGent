# Linux 手册来源检索基线（v1）

本次评测回答的是“前 5 个检索块中是否出现预期手册”，不是“这些块是否足以回答问题”。评测集及预期来源见 [evaluation_v1.json](../tests/rag/evaluation_v1.json)，与来源标注同时构建，不是独立测试集，不可据此估计真实用户问题的准确率。

## 配置与方法

- 时间：2026-10-28，使用本机 Qdrant 1.20.0、`linux_manual_v1` 集合和百炼 `text-embedding-v4`（1024 维）；首版快照为 8 本手册、306 个分块。
- 评测集 `linux-manual-eval-v1`：24 个标注来源问题（每本手册 3 个中文问题）及 8 个预期无对应资料问题。预期来源是人工设计的主目标，并不排除其他手册中的相关段落。
- 每个问题单独请求一次 Embedding，返回最多 5 个分块；来源指标按分块排序计算，多个分块可来自同一手册。接口失败按未命中计入正例分母并单独报告。
- 评测集 SHA-256：`20ef6776578e13cba2dd0a49f9e58563d53d908faab1008144a0ad31762a5549`。本次评测报告保存在本机被 Git 忽略的 `artifacts/evaluation/linux-manual-eval-v1.json`，包含问题、来源、分数及最多 160 字符的摘录，不包含完整分块或密钥。

## 结果

| 指标 | 结果 |
|---|---:|
| 请求失败 | 0 / 32 |
| 正例首条来源命中 | 22 / 24（91.7%） |
| 正例前 5 条来源命中 | 24 / 24（100%） |
| 首个预期来源的倒数排名均值（MRR@5） | 0.958 |
| 无对应资料问题仍返回结果 | 8 / 8 |

24 个正例首条分数范围为 0.585–0.870；8 个无对应资料问题首条分数范围为 0.239–0.449。此样本量很小，且无对应资料样本包含与 Linux 术语关联较弱的问题；这组范围不能用于确定通用阈值，也不能把分数解释为概率或把缺少正确证据视为“检索成功”。

## 人工复核发现

- `grep-03`（grep 的退出状态）首条误命中 `man(1)` 的退出状态；第 2 条虽然来自 `grep(1)`，但只是用法概要。实际解释 grep 退出状态的分块 `808cd408-2727-5d9a-91d5-6afa475a96bc` 没有进入前 5 条。
- `ps-02`（进程状态码）首条误命中 `man(1)` 的退出状态；第 2 条虽来自 `ps(1)`，不是状态码正文；包含状态码说明的分块在第 3 条。
- `ls-02`（显示隐藏文件）前 5 条包含多个 `ls(1)` 分块，因此来源指标命中，但包含 `-a, --all` 说明的分块 `cff112e7-c7fe-5e13-ad31-299fbc293a7f` 没有进入前 5 条。
- 无对应资料查询仍返回最近邻；如关于 SSH 和 Git 的问题首条相似度约为 0.449 和 0.446。现阶段没有经过验证的拒答策略，后续 Agent 需要判断证据是否足够。

这些问题表明只看来源会高估可回答性。当前没有改动分块、向量集合或排序规则；下一轮应先为更多问题标注可回答的证据块，再比较分块和排序调整，并使用独立问题集验证。
